    How the system works

    5 DS • 6 ALG

    1. Array

    Stores the master event, student, and registration collections.

    events[] • students[] • registrations[]

    2. Queue

    Pending registrations follow FIFO processing.

    enqueue → dequeue

    3. Stack

    Recent system actions follow LIFO history.

    push → pop

    4. Hash Table

    Student IDs map to buckets for fast lookup.

    hash(StudentID) → bucket

    5. Binary Search Tree

    Events are indexed by Event ID for ordered traversal and search.

    insert • search • inorder
